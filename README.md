# ScoreStream

Учебный backend-проект для обработки результатов участников и построения рейтингов в режиме реального времени.

## О проекте

ScoreStream принимает события о начислении очков, обрабатывает их асинхронно и предоставляет API для получения рейтингов участников.

Основная архитектурная идея — разделение приёма событий, их обработки и получения результатов.

## Технологии

- **Go** — backend-разработка.
- **PostgreSQL** — хранение событий и результатов.
- **Apache Kafka** — асинхронная обработка событий.
- **Redis** — хранение и получение рейтингов.
- **gRPC / REST** — взаимодействие с сервисом.
- **Protocol Buffers** — описание gRPC API.
- **Docker Compose** — локальное окружение.
- **GitHub Actions** — автоматизация проверок.

## Цель проекта

Практическое изучение backend-разработки и распределённых систем на примере компактного сервиса.

Основное внимание уделяется:

- Event-driven архитектуре.
- Асинхронной обработке данных.
- Идемпотентности и надёжности обработки событий.
- Транзакциям и согласованности данных.
- Работе с Kafka, PostgreSQL и Redis.

Проект развивается постепенно, начиная с минимального работающего MVP.
